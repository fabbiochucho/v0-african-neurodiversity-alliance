# Data processing agreements

Every vendor that handles ANDA users' personal data, and the agreement that covers it. Recorded 17 October 2026. Update this file in the same PR that adds or removes a vendor (see `AGENTS.md`).

| Vendor | What it does for ANDA | Agreement | Status |
|---|---|---|---|
| Supabase | Database, sign-in, file storage | [DPA](https://supabase.com/legal/customer-resources/data-processing-addendum), part of the [terms](https://supabase.com/terms) | In place (incorporated in the terms) |
| Vercel | Hosting, Vercel Analytics | [DPA](https://vercel.com/legal/dpa) | In place (standard DPA, confirmed by the owner 17 Oct 2026) |
| Cloudflare | Workers AI, Turnstile | [Customer DPA](https://www.cloudflare.com/cloudflare-customer-dpa/) | In place (standard DPA, confirmed by the owner 17 Oct 2026) |
| Resend | Email (reports, invites, digest) | DPA updated 31 Dec 2025 | **Signed** via DocuSign; the owner holds the copy (not in this public repo) |
| Flutterwave | Payments | [Merchant agreement](https://app.flutterwave.com/dashboard/onboarding/agreement) (accepted in the dashboard), [privacy notice](https://flutterwave.com/us/privacy-notice), [dispute privacy](https://dispute.flutterwave.com/privacy) | In place (merchant agreement) |
| Paystack | Payments | [Merchant privacy policy](https://paystack.com/privacy/merchant), [terms](https://paystack.com/terms?q=/za/terms), support articles [2131458](https://support.paystack.com/en/articles/2131458) and [2132162](https://support.paystack.com/en/articles/2132162) | In place (merchant terms) |
| WhoGoHost (Go54) | Hosts the becomechange.institute mailboxes (privacy@, dpo@, anda@) that receive data requests and reports | [Privacy policy](https://whogohost.com/tos/privacy-policy/), [data privacy notice and consent](https://whogohost.com/tos/data-privacy-notice-and-consent/), [Go54 privacy policy](https://www.go54.com/privacy) | Covered by their privacy terms; no separate signed DPA |

Lovable's DPA ([page](https://lovable.dev/data-processing-agreement), [signed PDF](https://lovable.dev/documents/Lovable_DPA_17Nov2025_Signed.pdf)) covers abiolaoshunniyi.lovable.app. This app doesn't use Lovable.
